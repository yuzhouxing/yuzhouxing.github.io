解谜攻略（全收集 100%）
1. 先在东城门点击“残碑”→“拓下碑文”，随时可点“万仙卷宗”查看缺项。
2. 收集机关材料：
| 天机棋局 | 丹阁金棋、民宅黑棋、钟楼白棋、仙牢玉棋、铁匠铺铁棋 |
| 五音古钟 | 东城内院铜轨、藏经阁钟谱、城主府钟诏 |
| 搬山断桥 | 民宅木牛、丹阁绞盘、铁匠铺锁链 |
| 阴阳八门 | 丹阁阳石、地下密道阴石、仙牢生石、铁匠铺锁石 |
| 仙牢旧案 | 天牢刑诏、仙牢囚锁、地下密道阵图 |

3. 十二处核心解谜按以下顺序操作：

- 四象锁井：青龙 → 朱雀 → 白虎 → 玄武。
- 天机棋局：中枢 → 黑 → 白 → 玉 → 铁。
- 北斗星灯：天枢 → 天璇 → 天玑 → 天权 → 玉衡 → 开阳 → 瑶光。
- 五音断律：先“合律”，再 宫 → 商 → 角 → 徵 → 羽。
- 搬山断桥：木 → 火 → 土 → 金 → 水。
- 阴阳八门：生 → 休 → 开。
- 西城真碑：选“缺字碑”。
- 南城天平：鼎 → 石。
- 城主府四锁：先集齐四方印，再 北 → 东 → 南 → 西。
- 古城地底脚印：断痕 → 重痕 → 雾痕；注意闪避门槛。
- 演武场：走“无锋路”。
- 仙牢旧案：八门完成后唤醒囚魂，带齐三证据到监察殿，判词选“守誓”

 隐藏剧情六项：
- 残破仙碑：已在开局拓下。
- 无名仙骸：断桥通后进后山，先读遗书，再安葬。
- 破碎仙兵：铁匠铺先查看炉膛，再“以仙元温养”。
- 仙童残魂：答案依次“万仙古城 → 登仙残卷 → 仙墟广场”；牵出民宅，带到广场安置。
- 古城壁画：先查看广场旧誓，再读“城 → 兵 → 锁”。
- 重钟旧誓：钟楼先敲第一声；五名守关全部击败后再敲第二声即可，避免提前强化 Boss
