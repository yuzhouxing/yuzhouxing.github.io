# 武仙传说 · 攻略总集

在线访问：<https://yuzhouxing.github.io/wxmud1/>

## 收录

- **76 篇攻略**，约 27 万字，182 张配图
- 7 大分类：新手开荒 / 副本禁地 / 武学门派 / 机制数值 / 装备炼制 / 丹药符箓 / 插件脚本
- 原文下载：`assets/files/` 保留 docx / doc / pdf / xlsx / txt 原档
- 旧版脚本库与丹药速查：`_legacy/`

## 功能

- 全文检索：标题、标签、正文一起搜，支持 `Ctrl/⌘ + K` 命令面板
- 章节导航：长文自动生成侧边目录，滚动高亮
- 图片灯箱：点开看大图
- 键盘操作：`/` 搜索、`J` `K` 翻篇、`←` 返回
- 手机适配
- 纯静态，无后端无依赖

## 结构

```
index.html          入口（单页应用）
data.js             全部攻略数据
assets/css/main.css 样式
assets/js/app.js    交互逻辑
assets/img/         配图（WebP）
assets/files/       原始文档
_legacy/            旧版脚本库页面
```

## 更新

新增攻略后重新生成 `data.js` 与配图即可，其余文件无需改动。
